# ტესტები

ყველა ტესტი ერთ ადგილას. მთავარ გვერდზე ტესტები ქარდებად ჩანს, კურსების მიხედვით.

**საიტი:** https://learn-easily.github.io/tests/

## სტრუქტურა

```
engine/index.html               მთავარი გვერდის შაბლონი (ქარდები, ჩანართები, ძებნა)
courses/
  <კურსი>/course.json           {"title", "order"}: ერთი კურსი = ერთი ჩანართი
  <კურსი>/<NN-slug>/
    test.html                   ტესტი (ერთი თვითკმარი HTML)
    test.json                   {"title", "badge"?, "topics", "duration", "questions", "points"}
build.py                        აწყობს index.html-ს და <კურსი>/<ტესტი>/ საქაღალდეებს root-ში
```

> root-ის `index.html` და `csharp/`-ის ტიპის საქაღალდეები ბილდის შედეგია. ხელით არ შეცვალო: შეცვალე `courses/` და გაუშვი ბილდი.

## ახალი ტესტი

1. შექმენი `courses/<კურსი>/<NN-slug>/test.html` და `test.json`.
2. ახალი კურსისთვის დაამატე `courses/<კურსი>/course.json`.
3. გაუშვი `python3 build.py`, შემდეგ commit და push `main`-ზე.

## Badge

`test.json`-ში არასავალდებულო `"badge"` (მაგ. `"შუალედური"`) ქარდზე ტესტის ნომრის გვერდით ჩანს და ძებნაშიც მოიძებნება.

## ტესტის ქცევა (ყველა ტესტი)

- **არეულობა:** კითხვები სექციის შიგნით, პასუხების ვარიანტები, ასაწყობი ხაზები და „შეავსე“ სიები თითო სტუდენტთან სხვა რიგშია. ეკრანზე კითხვები 1, 2, 3… ნომრებით ჩანს, არა `A3`-ით. რიგი ბრაუზერში ინახება და განახლებისას არ იცვლება.
- **დაკავშირებული კითხვა:** თუ კითხვა წინას ეყრდნობა („წინა კითხვის…“), EXAM-ში `"follows": true` მიუთითე — ის ყოველთვის წინას მოჰყვება.
- **დასრულება:** ჩანს მხოლოდ ქულა და სტუდენტის საკუთარი (დაბლოკილი) პასუხები. სწორი/არასწორი და ახსნები არ ჩანს.
- **ფანჯრიდან გასვლა:** ყოველი გასვლა (≥ 1 წმ) ითვლება ხანგრძლივობით: ზედა ზოლში, შედეგში და PDF-ში. ფანჯრის გარეთ ყოფნისას კითხვები ბუნდოვანდება.
- **შენიშვნა AI-სთვის:** თითო კითხვაზე მკრთალი და უხილავი ტექსტი, რომ AI-მ არ უპასუხოს. გარანტია არ არის.
- `csharp/01-basics` ხელით სწორდება: PDF-ის პასუხების ფურცელში ორიგინალი ID-ები და ასოებია, ანუ ძველი გასაღები მუშაობს.

## კითხვის ტიპები

`03-oop` ტესტიდან ძრავს ოთხი ტიპი აქვს: `mc` (ერთი სწორი), `multi` (რამდენიმე სწორი), `order` (ხაზების დალაგება ▲ ▼ ღილაკებით; ნაწილობრივ სწორ რიგს — ქულის ნაწილი) და `fill` (კოდში ცარიელი ადგილები `⟦a⟧`, თითოეულზე სიიდან არჩევა).

## გასაღები

რეპო public-ია, ამიტომ სწორი პასუხები აქ **არ** ინახება, არც `test.html`-ში, არც სხვაგან.
